# Lien de partage d'une usine

`#usine:ModularFrameHeavy*2,AluminumIngot*60;IronIngot=Alternate_PureIronIngot,Water=;Stone=MinerMk3.Pure,OreIron=Impure`

- Avant `;` : les objectifs `pièce*débit` (débit en notation décimale à point, 2 décimales). Après : les recettes choisies `pièce=recette`, une recette vide signifiant « fourni de l'extérieur » (ou « ressource brute » pour une ressource). Seuls les choix qui diffèrent de la recette par défaut sont écrits.
- Après un second `;` (optionnel, ajouté en novembre 2026) : les réglages d'extraction `ressource=Extracteur.Pureté`, l'un ou l'autre pouvant manquer (`Stone=MinerMk3`, `OreIron=Impure`). Extracteurs : classe sans `Build_` ni `_C` (`MinerMk1`, `MinerMk2`, `MinerMk3`, `OilPump`, `WaterPump`, `FrackingExtractor`) ; puretés : `Impure`, `Pure` (`Normal` n'est pas écrit). Sans réglage de recette, la partie du milieu est vide : `#usine:ModularFrameHeavy*2;;Stone=MinerMk3.Pure`. Les anciens liens (une ou deux parties) restent lus.
- Les classes du jeu perdent leur préfixe `Desc_` / `Recipe_` et leur suffixe `_C` quand elles les ont ; sinon la classe complète est écrite.
- Le lien porte une seule usine : « Partager » écrit l'usine active.
- À l'ouverture, les pièces et recettes inconnues sont ignorées. Sans aucune usine, le lien crée l'usine « 1 ». Si une usine enregistrée est identique, elle devient l'usine active (toast). Sinon une fenêtre demande où l'ouvrir : nouvelle usine (par défaut, avec son nom) ou une usine existante ; à 5 usines, l'usine active est proposée et « Nouvelle usine » est grisé. Remplacer une usine qui a des pièces passe par le bouton « Remplacer l'usine X », avec un avertissement ; le nom et les choix de transport de l'usine sont gardés. L'adresse redevient ensuite `#usine`. Les réglages de Transport ne sont pas partagés ; ceux d'extraction le sont.
- Bouton « Importer » de Mon usine (et « Importer une usine » quand elle est vide) : une modale où coller le lien, avec un bouton « Coller » si le presse-papiers est lisible (contexte sécurisé). Le lien est contrôlé à la saisie et de nouveau sur « Importer » (`shareFromText`) : il doit contenir `#usine:` (ou commencer par `usine:`) et au moins une pièce reconnue ; l'adresse du site n'est pas vérifiée. Le bouton « Importer » (et la touche Entrée) reste désactivé tant que le lien n'est pas valide. Messages : adresse de Mon usine sans pièce (`…/#usine`), lien qui n'est pas une usine partagée, aucune pièce reconnue ; chacun renvoie au bouton « Partager ». Si au moins une usine existe, la même fenêtre propose l'usine qui reçoit le lien (nouvelle par défaut, ou « Remplacer l'usine X ») ; pas de seconde confirmation. Message si l'usine choisie est déjà identique au lien.
- Code : `shareCode`, `parseShare`, `shareFactory`, `openShared`, `applyShared`, `applySharedTo`, `importFactory`, `destHtml` dans `app.js`.
- **Format public** : le modifier casse les liens déjà diffusés. Pour le faire évoluer, garder la lecture de l'ancien format.
