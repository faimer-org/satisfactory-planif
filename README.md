# Planificateur Satisfactory

**https://faimer-org.github.io/satisfactory-planif/**

Planificateur de production pour Satisfactory 1.2, en français, à partir des données officielles du jeu.

- **Fiche pièce** : de quoi une pièce est faite, dans quelle machine, où elle sert, et les recettes alternatives.
- **Mon usine** : pour les pièces et débits voulus, chaque étape jusqu'aux ressources brutes, le nombre de machines, l'énergie et les sous-produits. Jusqu'à 5 usines, à nommer comme vous voulez. Un lien permet de partager une usine.
- **Transport** : combien de tapis, de wagons ou de drones pour acheminer les ressources d'une de vos usines, ou de celles que vous saisissez.

Fonctionne dans le navigateur, sans compte ni installation ; vos usines restent enregistrées sur votre appareil.
